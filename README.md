# bearing-failure-prediction
# predictive maintenance: Bearing Failure Detection

Predicting bearing failure 2 weeks before they happen using vibration data + Python.
Built as part of my 90-day AI/ML portfolio.

**progress**: Unplanned machine downtime costs manufacturers millions per hour.
**Solution**: ML model that flags "normal vs early failure" from sensor data.
**Tech**: Python, pandas, numpy, scikit-learn, matplotlib, FFT for signal processing

**Progress:**
- [ ] Data loading + cleaning
- [ ] Feature extraction with FFT
- [ ] Train baseline model
- [ ] Results + visualisations

**Dataset**: CWRU Bearing Dataset - industry standard for this problem
